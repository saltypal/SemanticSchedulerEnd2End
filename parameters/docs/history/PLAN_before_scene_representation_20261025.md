1. **Audit and reuse prepared data.** Retrieve actual source/annotation/exposure
   receipts when available. Use existing small development images first; do not
   inspect reserved final groups for producer or threshold selection. LADI/MEDIC
   are the only launched data sources. Select a separate bounded object-annotated
   development cohort with legitimate access for localization; image-level labels
   cannot validate bounding boxes. Dataset expansion remains annotation-gated.
2. **Define observable evidence per parameter.** Record units, applicability,
   predictions, source, reference labels, missingness and failure modes. Keep
   operator paragraph and supported clauses separate. No new hidden importance
   weights; historical I/F remain baselines. Original-image pixels, filenames and
   model-generated descriptions are not automatically independent reference truth.
3. **Implement a shared visual-evidence layer, not a scene-model fleet.** Compare
   one pinned YOLO-World checkpoint against the already available Grounding DINO
   on the same 100–200 annotated development images; same entity vocabulary and
   source-group folds. Use CLIP as the initial shared global image/text embedding
   provider; SigLIP remains a separately assessed alternative. Detectors predict
   objects/boxes, not certified damage, distress, physical range or causal relations.
   Condition predictions require separate supported heads/labels. Overlapping
   scene predictions select applicable evidence, never a mutually exclusive gate.
4. **Persist reusable producer output separately from parameters.** Cache normalized
   global embeddings, canonical object names/boxes/scores, supported condition
   predictions, preprocessing transform, original dimensions, model/prompt hashes,
   timings and failures. Ground-truth labels stay in a separate evaluator table.
   Cache static relevance per mission/version if useful. Derive novelty/rarity from
   a declared causal sender history; they are not fixed image attributes. Original
   mission/image provenance and raw object evidence need not all be transmitted.
5. **Direct parameter validation before scheduling.**
   - Relevance: independently annotated mission relevance, PR-AUC and paired
     mission changes where labels support both. Compare global similarity and
     supported condition/entity evidence; neither defines its own correctness.
   - Novelty: exact repeats, controlled appearance perturbations retaining known
     facts, and newly visible annotated facts only where correspondence exists.
     Report appearance difference separately from additional task evidence. Natural
     new-view knowledge remains unresolved without asset correspondence.
   - Rarity: verify smoothed frequency/surprisal against hand-counted causal
     histories, support/window sensitivity. Do not call rarity urgency/importance.
   - Spatial: detector precision/recall/AP on compatible object annotations and
     normalized object extent error. Box-area prominence is an approximation;
     segmentation masks support visible-pixel area. No physical-distance claims.
   - Complexity: validate relevant entity counts/diversity against annotations.
     Count/entropy are scene-content diagnostics, not semantic-depth ground truth.
   - Reliability: per-claim correctness, Brier score/reliability bins and support;
     calibrate on training-side groups. Detector scores are not mission-claim
     probabilities and averaging them is not image reliability.
   - Time/geography: trusted metadata correctness and deterministic unit tests.
     Synthetic timestamps are engineering tests, not natural temporal validation.
   Unsupported cells remain explicit. VLM outputs may nominate hypotheses, never
   silently supply gold labels or certify trapped/injured people.
6. **Interpretability/contrast audit.** Persist examples of same parameter vectors
   with different annotated situations, changes under irrelevant appearance shifts,
   missed conditions and relation failures. A person plus a building plus damage
   does not establish a person trapped in the building. Do not expand the header
   simply because a model can output another number; retain a measurable reason.
7. **Then run the scheduler usefulness experiment.** Freeze a validated extraction
   candidate before grouped selection. Begin with individual groups, transparent
   core combinations and strong relevance-plus-repeat baselines. Full subset
   search follows only on groups with supported evidence. Report direct parameter
   validity separately from A10 ordering utility. Same-information comparisons and
   extraction/byte costs remain mandatory.
8. **Optional information-loss comparison.** Compare compact parameters against a
   richer descriptor under identical independent targets, tasks and held-out
   groups; report its additional bytes/compute. It is an information-content
   comparison, not a same-header-policy baseline. Ground-truth object labels may
   define an evaluator-only ceiling, never a deployable input. No descriptor
   experiment is currently implemented in the launched snapshot.

## Parameter candidates

Shared/global candidates: task-conditioned relevance, causal transmitter KB
novelty, optional rarity, claim reliability, capture timestamp/allowed delay.
Scene-specific evidence: overlapping scene/event predictions and optional localized
target visibility, count/entropy diagnostics and trusted geofence metadata.
The weighted I and exponential F definitions remain historical baselines.
One CLIP/SigLIP encoder is loaded at a time; one optional DINO detector is tested
only within a measured budget. No separate detector fleet per scene.

The original mission paragraph is retained. Explicit short observable conditions
feed the text encoder; unsupported language is not silently interpreted. Global
embedding novelty does not certify new incidents or physical asset identity.

## Evaluation and selection rules

- Native atoms: `(mission,parent_image,supported_claim)`; exact copies inherit
  atoms. Different images need not represent independent real-world objects.
- Object/crop atoms require spatial annotation support; image labels do not
  propagate to arbitrary crops. No natural cross-view claim from copies/crops.
- Queue:32 ready jobs,4 logical senders,K=10. Native/relevant-only/copy arms are
  reported separately; unavailable arms are counted, never silently fabricated.
- A10/coverage@10, redundancy, misses/failures and measured producer/policy cost.
  Critical recall only for supported critical labels. No throughput objective.
- Pilot: one exposed-development grouped split, restricted candidate comparison;
  it cannot establish final selection or statistical superiority.
- Cloud: fresh20% final groups;3 outer/3 inner development group folds where
  label/group support permits. All supervised heads/calibration/transforms and
  scorers fitted inside the applicable fold. Never fit using final flooding labels.
- Seven feature groups, Ridge alpha .1/1/10 and all available subsets. Fixed-budget
  boosted-tree check of core/full/top3 inner subsets. Remove ablated fields from
  history features; distinguish output and whole-producer ablations.
- Select simplest within max(.005A10,1SEbest); then measured producer cost/header
  bytes. Final gain claim requires >=.01A10 and a positive grouped paired interval.
  Queue repetitions are not independent observations; low group support means
  descriptive results only.
