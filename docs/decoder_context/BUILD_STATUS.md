`D:\Bunker\BaseCamp\WirelessCommunication\SemanticCommunication\SemanticSchedulerBuild`

Base source is detached revision `2f16785a16dd9c58ce12c98b502087cc212b279b`. Four prior diagnostic implementation/test files were copied and individually hashed. Original working repositories, source datasets, historical results and model files were preserved. This implementation is local and uncommitted; HEAD alone does not identify it. Use operation source hashes and the final delivery manifest.

The receiver accepts `[32-byte ParameterHeader][complete opaque payload reference]`, selects one whole job, and waits for matching completion. Successful completion adds its immutable header snapshot to delivered history; a failed attempt adds no semantic history. No automatic retransmission, radio grant or preemption is introduced.

### Runtime modules

| Component | Delivered behaviour |
|---|---|
| `INFRA/decoder_queue.py` | Historical enqueue/dispatch retained; ready snapshots, checked removal, injected profile registry and episode reset |
| `INFRA/decoder_service.py` | Single-owner in-flight lifecycle, monotonic clock, exact identity completion, failed-job handling and history bounded to 32 |
| `Scheduler/decoder_scheduler.py` | FIFO/RR/random preserve their rules when semantic values are all unavailable |
| `Scheduler/contextual_decoder_scheduler.py` | Immutable context, static-policy wrapper, 39 header/context features, optional known-task indicators, explicit overlap penalty, NumPy linear/tree inference, nonfinite fallback counter |
| `SemParam/decoder_context_profiles.py` | Additive profiles 2001 building presence, 2002 binary building damage, 2003 structural-flooding transfer |
| `SemParam/decoder_parameters.py` | Registry injection through memory/header/profile lookup; old profiles and wire size retained |
| `SemParam/decoder_extractors.py` | Optional profile registry for fresh task-text alignment; original defaults retained |

Policies receive values/masks, ready jobs, delivered-header context and declared task/progress metadata. They receive no images, latent tensors, native labels or evaluator fact identities. Transmitter KB novelty remains causal query-before-commit and retains its sender-history meaning.

The service is a serial single-owner API, not a thread-safe multiworker queue. Arrival admission remains transport/caller-owned. Decoder execution success does not certify semantic reconstruction success.

### Data and evaluator modules

`INFRA/decoder_datasets.py` supports:

- LADI cached evidence and curated manifests, consuming native booleans rather than prototype priority columns.
- MEDIC TSV stress labels without relabeling general damage as building-specific truth.
- RescueNet/FloodNet image-mask pairs with explicit native class maps and annotation-completeness flags.
- xBD post-event single-ring polygon annotations, source-qualified fact identities and deterministic half-size/quarter-stride windows plus the full image.
- The 95% visible-polygon credit rule, explicit exclusions, component grouping and split-isolation checks.

Unsupported mask codes, unsafe/missing paths, inconsistent geometry and unsupported labels fail explicitly. Unknown labels remain unavailable. Natural asset matching is not inferred from similarity. Polygon holes/multipolygons are excluded, not approximated. Near-duplicate edges can be injected into grouping; automatic cross-source perceptual duplicate discovery and spatial provenance recovery are not yet delivered.

`INFRA/decoder_semantic_benchmark.py` implements source-denominator weighted union coverage, marginal gain, critical-fact recall where explicitly supplied, failure/unsupported-claim accounting, weighted redundancy, an exact subset-DP reference for N<=12 and evaluator-only greedy references. Controlled crops are not natural different-camera views.

### Training and replay modules

`INFRA/learning/decoder_context_training.py` implements:

- Train-only imputation and stable weighted standardization.
- Equal decision/episode contribution for marginal-gain MSE.
- Ridge and 50-tree gradient boosting exports.
- Complete tree validation and NumPy inference equivalence checks.
- Candidate field/mask subsets removed from every derived history/distance feature.
- Portable checksummed model JSON with known-task conditioning where enabled.

`INFRA/learning/decoder_context_study.py` implements the native-cache control route:

- Serialized new-profile headers and real service-controller replay.
- A-only grouped inner subset selection, fixed disjoint B calibration, and optional grouped outer selection evaluation.
- Linear, tree, pointwise, masks-only, task-conditioned, specialist, signature and utility/overlap policies.
- Model file freeze before held-out scheduler-task evaluation; structural flooding receives no target calibration.
- Per-episode orders, traces, outcomes and provenance.

The default command is a restricted CPU smoke. `--all-subsets` exposes the complete linear subset screen and `--nested` runs the grouped outer route; neither was executed in this delivery on the old data. Nonlinear eight-configuration model selection, full multi-source training ingestion and a new locked final-study runner remain downstream integration work. Do not describe fixed tree/specialist configurations in the smoke as validation-selected winners.

## Actual codec integration status

`EncDec/integration/decoder_payload_cache.py` implements aspect-preserving resize/padding, annotation point transforms, per-image seeded AWGN before scheduling, cached received tensors, payload/reference checksums and decode-only timing. The same cached received payload can be reused across policy orders. No source-model weights or upstream codec source were changed.

The first strict attempt verified all three checkpoint hashes (656,647,926 bytes read) then rejected the torch-2.14 runtime. That failure remains preserved. A bounded environment scan found the existing `.venv-models` interpreter with Python 3.12/PyTorch 2.10. Its first attempt then found missing timm. Installing the repository-declared `timm==1.0.28` with `--no-deps` changed only that package; no torch upgrade/downgrade or checkpoint edit occurred.

Strict inference subsequently passed in the matching environment. One-image wall time was 41.733 s (encode 16.184 s, decode 11.263 s). The five-image run took 139.967 s wall, with 71.378 s total encode and 56.254 s total decode. PSNR ranged 29.1066–32.9624 dB; all exact-pixel flags were false. Five received-payload records each have 196,608 complex channel uses. Tensor/file storage sizes are recorded separately and are not digital payload-bit measurements. Artifacts are in `results/decoder_context/implementation_ops/20261024T082550Z/codec_matched_runtime_5_timm/`.

Pillow 12.3.0 in that existing environment is outside the declared EncDec extra bound `<12`. The observed smoke succeeded with it; this does not certify the full declared dependency matrix. Original argparse/runtime/dependency failures and their recovery remain in OPERATIONS.md. No fixture adapter is counted as actual Swin inference.

`INFRA/decoder_codec_driver.py` now connects supplied source-only headers, policy selection, the single-owner service and decoding of the same cached received tensors. `SemParam/decoder_native_classifier.py` and `INFRA/learning/decoder_codec_semantic_smoke.py` provide a local frozen LADI partial-header preflight and separate model-assessed reconstruction outputs. Only S/I can be produced in this partial path; other fields retain unavailable masks. It does not fabricate full eight-field extraction or independent semantic truth.

The complete path was executed in run `20261024T083335Z`: five images, source-only partial headers, FIFO/I/learned policies, and strict Swin inference from the same received tensors. All **15 decodes succeeded**, with identical source payload hashes across policies and zero re-encoding/channel resampling. Source classifier processing completed ten passes (five references and five reconstructions) in 42.789 s. S was available for four headers and I for all five; R/N/Q/F/P/C remained masked. The learned order equaled I. The initial cohort contains five native-positive building-presence examples, so it is a functional preflight, not a diverse semantic benchmark.

Controller replay wall time was 186.085 s. Modeled cumulative dispatch-plus-inference endpoints were FIFO 56.9365 s, I 56.9220 s and learned 59.8245 s. These exclude successful artifact input/output work and are neither full receiver latency nor a speedup result. The separate frozen classifier marked four of five reconstructions positive; this is model-assessed class retention, not independent fact preservation. The actual source/policy/codec path and claim boundary were reviewed in C1_ASSESSMENT.md.

After that successful run, a metadata-only hardening change made the CLI's actual-codec flag depend on a successful measured-checkpoint result instead of being unconditional. It prevents future all-failed payload runs from claiming successful codec execution. The three executed source files were copied to `20261024T083335Z/verified_executed_sources/` and their hashes verified against operation/review records before this final change. Actual inference was not rerun for the flag change; its fixture/failure contract is covered by the final regression.
