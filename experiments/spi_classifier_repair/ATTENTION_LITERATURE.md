# Attention and ordinal SPI heads: primary-source review

Research snapshot: 2026-10-28. Research only; no training, downloads of weights, model execution, or Kaggle submission. This is the attention/ordinal branch of the classifier review, not an exhaustive review of every classifier. The local `JOINT_BENCHMARK.md` supplies the four-class image-in/output contract and evaluation boundaries; published task results below are evidence of mechanisms, not SPI accuracy predictions.

## Decision

Include attention heads as a distinct experimental family. Start with **gated ABMIL**, **one-query attentive pooling**, and **CaiT-style class attention** on the *same frozen image patch tokens*, with mean-pooling plus linear/MLP controls. These test whether retaining and selecting spatial information helps relative to pooled-vector classifiers. Include **ACMIL** as the substantive multi-branch/regularization alternative. Keep **DSMIL**, **TransMIL**, and a small **Perceiver-style latent bottleneck** in the compatibility shortlist, with conditional priority described below. Neither their pathology success nor their architectural capacity establishes that they will outperform vector classifiers on the current pseudo-labels.

**CORAL/CORN are output parameterizations and losses, not attention pooling architectures.** Cross nominal four-way cross-entropy versus ordinal output on matched representations. Do not assume that ordering repairs supervision ambiguity, establishes human correctness, or necessarily maximizes exact-class accuracy.

## Contract and fair adaptation

Proposed common interface: image encoder emits `H: [B,N,D]`, optionally valid-token mask `[B,N]` and actual grid `(height,width)`; head returns four mutually exclusive class logits or three ordered exceedance outputs. `N` is tokens **within one image**, never images from different users/events concatenated into a bag. A single global embedding `[B,D]` cannot recover discarded patch information: existing pooled feature caches are insufficient for this branch. Expose/re-extract native patch tokens and record layer, normalization, positional encoding, class/register-token treatment, mask, shape, dtype and revision. Do not call scalar features or duplicated global vectors “patch tokens.”

Use the same image cohort, grouping, folds, labels, preprocessing, encoder revision, and token layer within each head comparison. Training-only selection and fold-local transformations remain required. The 96 already exposed development records are descriptive, not a fresh test or hyperparameter selector. Native encoder tokens may already contain global context; an extra head self-attention layer can be redundant. That is an empirical question, not a reason to exclude it in advance.

## Published candidates and original evidence

| Method and primary paper | Original input, output and evaluation | Mechanism relevant to SPI | Required adaptation / important limitation |
|---|---|---|---|
| **Attention-based Deep Multiple Instance Learning (ABMIL), ICML 2018** — [Ilse et al.](https://proceedings.mlr.press/v80/ilse18a.html) | Variable-size instance bag → binary bag probability; standard MIL benchmarks, MNIST bags and two histopathology datasets. Not a four-class urgency model. | Independent token scoring; gated form `a_i ∝ exp(wᵀ[tanh(Vh_i) ⊙ sigmoid(Uh_i)])`; weighted sum → classifier. Both plain and gated forms are published. | Replace the reference MNIST CNN/binary sigmoid with native image tokens and four logits. Pooling does not create pairwise token interactions; position must already be represented or added deliberately. Relative attention is not a calibrated probability of patch urgency. |
| **V-JEPA 2 attentive probe, 2025** — [Assran et al., §5 and App. C](https://arxiv.org/html/2506.09985v1) | Frozen image/video encoder outputs → task classifier; SSv2, Diving-48, Jester, K400, COIN and ImageNet. Published protocol includes multiple video views. | Learned query cross-attends to token keys/values, then linear classifier. Published classification probe has **three token self-attention blocks followed by one query cross-attention block**. | Official code defaults `depth=1`, which omits those self-attention blocks. Report a depth-1 SPI pooler as a shallow adaptation, not reproduction of the full published probe. Reusing the pooler does not require using a video encoder. Video benchmarks do not establish single-image SPI performance. |
| **Dual-Stream Multiple Instance Learning Network for Whole Slide Image Classification with Self-Supervised Contrastive Learning (DSMIL), CVPR 2021** — [Li et al.](https://openaccess.thecvf.com/content/CVPR2021/html/Li_Dual-Stream_Multiple_Instance_Learning_Network_for_Whole_Slide_Image_Classification_CVPR_2021_paper.html) | WSI patch embeddings → slide diagnosis; CAMELYON16, TCGA lung and standard MIL benchmarks. Paper also uses contrastive embedding training and multiscale features. | Instance classifier finds a highest-scoring “critical” instance per class; learned similarity to that instance weights all values in a bag stream. Paper combines instance and bag streams. | Set feature dimension/classes and use exclusive-class loss/output deliberately; original code also supports negative/multi-label conventions. Do not silently reproduce its pathology preprocessing or SimCLR training. A spurious critical token can anchor the entire aggregation; argmax selection is discontinuous. |
| **TransMIL: Transformer based Correlated Multiple Instance Learning for Whole Slide Image Classification, NeurIPS 2021** — [Shao et al.](https://arxiv.org/html/2106.00908v2) | WSI patch embeddings → binary/multiclass slide prediction; CAMELYON16, TCGA-NSCLC and TCGA-RCC. | Two approximate Nyström attention layers with intervening multiscale depthwise-convolution positional encoding (PPEG); classify a learned CLS token. Models relations and neighborhood structure. | Reference input width is 1024, hidden width 512; code pads to a square by repeating initial tokens and forces CLS to CUDA. Adapt input/device, use true image grid and sensible padding/masks. An arbitrary reshape of an unordered bag is not real spatial correspondence. Exact reproduction and grid-correct SPI adaptation must be labeled separately. |
| **Data-efficient and weakly supervised computational pathology on whole-slide images (CLAM), Nature BME 2021** — [Lu et al.](https://pmc.ncbi.nlm.nih.gov/articles/PMC8711640/) | WSI patch features → diagnosis, with attention maps; renal/lung cancer subtyping and lymph-node metastasis, including independent cohorts. | Gated attention with single- or multiple-branch aggregation; training uses top/bottom attended instances for auxiliary positive/negative instance clustering. | Merely adopting its multi-branch pooler is not full CLAM. Instance pseudo-targets assume diagnostically positive/negative regions; a whole-image urgency label need not imply such patch labels. Adapt widths/classes and validate the auxiliary loss separately; bound top-k by valid token count. |
| **Attention-Challenging Multiple Instance Learning for Whole Slide Image Classification (ACMIL), ECCV 2024** — [Zhang et al.](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/06954.pdf) | WSI patch embeddings → slide class; CAMELYON16, BRACS, and private liquid-based cytology (LBC), using ImageNet ResNet18 and SSL ViT-S/16 features. | Multiple attention branches, branch classification and diversity regularization; stochastic masking of some top-attended instances during training reduces concentration. Authors provide gated-attention and MHA variants. | Keep branch/diversity losses if claiming ACMIL. Disable stochastic masking for normal inference; tune/clamp top-k relative to `N`. Masking may erase the only valid hazard cue in a small image. Authors' README reports that `mask_drop=0` can work better; masking gain is not universal. |
| **Going Deeper With Image Transformers (CaiT), ICCV 2021** — [Touvron et al., §3](https://openaccess.thecvf.com/content/ICCV2021/papers/Touvron_Going_Deeper_With_Image_Transformers_ICCV_2021_paper.pdf) | Full image transformer → ImageNet class; includes depth/stability changes and transfer evaluation. | Separate patch-processing stage from a late class-attention stage: only CLS is updated while it attends to fixed patch embeddings and itself, followed by classifier. “Class” means a summary token, not one query per output category. | Using only its late pooling stage on frozen external tokens is **CaiT-style class-attention head**, not the complete CaiT network. Match dimensions/head divisibility, normalization and residuals; no basis to transplant reported full-encoder accuracy. |
| **Perceiver: General Perception with Iterative Attention, ICML 2021** — [Jaegle et al., §3](https://arxiv.org/html/2103.03206v2) | Raw high-dimensional arrays + position → class; ImageNet, AudioSet audio/video, ModelNet40 point clouds. | Learned latent array cross-attends to input, processes a smaller latent sequence using self-attention, optionally re-queries input. Bottleneck decouples processing depth from input size. | A small head on encoder tokens is a Perceiver-style adaptation, not original raw-pixel Perceiver. Tune latent count; too few loses rare cues, too many removes efficiency advantage. Official repo is JAX/Haiku and now encompasses Perceiver IO; a PyTorch head is not a drop-in official implementation. |
| **Rank Consistent Ordinal Regression for Neural Networks with Application to Age Estimation (CORAL), PRL 2020; preprint 2019** — [Cao et al.](https://sebastianraschka.com/pdf/papers/2020-coral.pdf) | Neural representation → ordered age estimate; face age datasets. | `C−1` cumulative threshold tasks with shared final weight vector and different biases; binary extended targets encode ordering. | For four SPI ranks, three logits over an existing pooled representation. Shared direction is restrictive. Check monotonic probabilities in the actual implementation; theorem under its training conditions does not validate arbitrary early-stopped/adapted code. Ordered ranks do not imply equally spaced urgency. |
| **Deep Neural Networks for Rank-Consistent Ordinal Regression Based On Conditional Probabilities (CORN), preprint 2021; PRL 2022** — [Shi et al., §3–4](https://arxiv.org/html/2111.08851v3) | Neural representation → ordered label; age and image aesthetics, with text-rating experiments in supplement. | Separate conditional exceedance classifiers trained on conditional subsets; cumulative products convert conditional probabilities into monotone unconditional exceedance probabilities. Removes CORAL's final weight sharing. | Three conditional outputs for SPI. Conditional upper-rank subsets may be tiny; report their support. Do not treat raw sigmoid outputs as unconditional class probabilities. A coherent rank distribution is not proof of calibration or better exact classification. |

## Compatibility and cost matrix

These are analytical scaling estimates, **not measured FLOPs, memory or latency**. Let `N` be patch count, `d` hidden width, `r` attention scorer width, `q` learned pooling queries, `C=4` classes, `m` Nyström landmarks, `L` Perceiver latents, `s` latent self-attention layers and `t` cross-attention stages. Attention-interaction terms omit batch/head constants and must be added to projections/MLPs, often `O(N d²)`. Runtime stores token activations at least `O(Nd)` even when attention-score storage is linear. Fused attention can avoid materializing quadratic matrices without removing quadratic arithmetic.

| Candidate | Compatible representation | Attention interaction / score storage | SPI priority and reason |
|---|---|---|---|
| Mean/max + linear/MLP controls | Global vector or token pooling | Pooling `O(Nd)`; no learned attention scores | Required comparator; separates token availability from learned aggregation benefit. |
| Gated ABMIL | Unordered or positional tokens | Scorer `O(Ndr)`, pooling `O(Nd)`; scores `O(N)` | Core: small, clear learned-selection hypothesis. |
| Attentive pooler, depth 1 | Contextual patch tokens | `O(qNd)` interactions, `O(qN)` scores | Core: query-based alternative; one query versus small fixed multi-query ablation. |
| Published V-JEPA 2 depth 4 | Patch tokens | Three `O(N²d)` self-attentions plus query pooling; conventional scores `O(N²)` | Stronger comparator if memory/time permit. The shallow version does not cover this hypothesis. |
| CaiT-style late class attention | Contextual patch tokens | Per block `O(Nd)` interactions, `O(N)` scores; projections `O(Nd²)` | Core or matched alternative to one-query pooling; related mechanisms, not independent evidence. |
| DSMIL | Token bag | Core `O(NCd)`/`O(NC)`; official critical-instance **full sort** adds `O(CN log N)` | Conditional: test whether a critical localized cue helps; preserve both streams. |
| CLAM SB/MB | Token bag | Linear in `N` at fixed widths/branches; MB scores `O(CN)`; top-k + instance training overhead | Conditional: auxiliary clustering assumptions weaker for SPI; first compare pooler-only versus full loss. |
| ACMIL GA / MHA | Token bag | Fixed-branch pooling linear in `N`; diversity adds `O(branches² N)`, masking top-k cost in training | Core advanced candidate; directly tests attention concentration and complementary cues. |
| TransMIL | Ordered grid tokens | Approximate Nyström terms `O(Nmd + Nm² + m³)` plus projections; `O(Nm+m²)` scores | Conditional: geometry/relations hypothesis. For small `N`, approximation/landmark overhead may not beat exact attention. |
| Small Perceiver-style head | Positional tokens | `O(tNLd + sL²d)` interactions; scores `O(NL+L²)` | Conditional: most relevant for long token sequences or deeper processing; bottleneck may be unnecessary at 49–256 tokens. |
| CORAL / CORN output | Any pooled representation | No token interaction; CORAL shared score `O(d+C)`, CORN output `O(d(C−1))` | Orthogonal nominal/ordinal experiment; does not replace pooling/encoder comparison. |

Paper methods were inspected for V-JEPA 2, CaiT, ACMIL, Perceiver and ordinal methods; official method implementations were inspected for every head listed above. Some repeated PDF page retrievals for ABMIL/DSMIL/TransMIL timed out; their accessible paper task text and full relevant head source, and TransMIL HTML method, were used. ## Proposed comparison and stopping rules

1. Establish one encoder's token extraction and mean-pooling control. Check that sample/group identity, native token shape and preprocessing match; distinguish patch tokens from pooled outputs. Compare existing vector-head baselines to *token mean + the same head* before attributing gains to attention.
2. Compare gated ABMIL, depth-1 attentive pooling, CaiT-style class attention and ACMIL on identical tokens. Use a small training-only regularization/width search and matched search budget; no universal accuracy ranking is supplied by this literature. Keep named conditional candidates available when their hypothesis is relevant, rather than claiming the core four cover every architecture.
3. Cross nominal versus CORAL/CORN only on selected common representations; report exact-class accuracy, macro-F1, balanced accuracy, per-class precision/recall/F1, confusion, ordinal MAE and critical-class underprediction. Use proper normalized class probabilities for probability metrics. Rank order alone does not specify asymmetric operational error costs.
4. Measure both CPU and GPU end-to-end image inference on the same host: preprocess + encoder + head + transfers; warmed batch-one p50/p95 and cold load separately. Record head-only timing as a diagnostic, not pipeline latency. Measure process RSS, peak GPU allocated/reserved memory, serialized deployed state and parameters. For a GPU encoder/CPU head include token transfer `B×N×D×dtype_bytes`, not just pooled-vector transfer. Report quality-first results and CPU/GPU Pareto fronts; do not dismiss a higher-quality model solely for a modest cost increase.
5. Separate frozen feature extraction, head fitting/search, and inference. Report actual profiled operator coverage with 2 FLOPs/MAC; attention asymptotics are no substitute for CPU/GPU measurement. Do not add independently measured peak memories or mix machines. A `.70` per-class gate remains unmet until measured; selecting the best candidate does not authorize deployment.

If matched attention heads do not improve training-only grouped estimates beyond uncertainty, stop enlarging the head by default. Inspect whether encoder tokens contain the required visible cue and whether label boundaries are consistent. If extra token processing helps, test the relevant conditional architecture and ablate the added mechanism (e.g. ACMIL masking/diversity or full-token versus latent self-attention). Revisit more expensive encoders/training only through the canonical approved benchmark scope.

**Naming:** `ClassQueryTransformer` is a generic proposed local architecture name, not an identified published SPI model. Several class-specific queries plus cross-attention could be implemented using known components, but this does not make it CaiT, V-JEPA 2, CLAM or ACMIL. Describe exact query count, whether queries represent classes or latent summaries, token updates, losses and output decoding; call untested gains hypotheses and assess it against named baselines.
